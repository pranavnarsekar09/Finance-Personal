# Personal Finance & Life Operating System

A premium behavioral intelligence platform that combines financial management with health tracking.

## Features

- **Dashboard** - Daily overview with spending, savings, and health insights
- **Money** - Financial tracking, budgets, and expense management
- **Health** - Nutrition tracking, calorie monitoring, and wellness
- **AI Insights** - Behavioral analytics and smart recommendations

## Tech Stack

- React + TypeScript
- Tailwind CSS + shadcn/ui
- Framer Motion
- Recharts
- Vite PWA

## Getting Started

```bash
cd frontend
npm install
npm run dev
```
